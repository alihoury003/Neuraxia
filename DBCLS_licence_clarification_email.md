**Subject:** Licence clarification for BodyParts3D/Anatomography 4.3 FJ OBJ files used in an educational web application

Dear Database Center for Life Science team,

I am a medical student developing **Neuraxia**, a free, browser-based interactive 3D teaching atlas of the human brain and spinal cord for medical students. For its anatomy we used BodyParts3D/Anatomography **version 4.3** data: we selected 202 FJ OBJ components of the central nervous system (list attached), merged them into 182 named concepts, simplified the meshes, and converted them to compressed GLB files with full per-structure provenance (FJ/BP/FMA identifiers and file hashes recorded).

Before any public release, I would be grateful for written clarification of the licence terms, because the current database licence page (updated 2025-02-27) states **CC BY 4.0**, while the 4.3 release materials and several downstream sources describe BodyParts3D meshes as **CC BY-SA 2.1 Japan**:

1. Which licence governs the BodyParts3D/Anatomography **4.3 FJ OBJ files** obtained through the FJ endpoint — CC BY 4.0 or CC BY-SA 2.1 Japan?
2. Does the 2025-02-27 CC BY 4.0 database licence apply to the 4.3 object set, or only to specified archive downloads/releases?
3. May simplified/merged/converted GLB adaptations be redistributed inside a **free educational web application**? Would a possible future **commercial** version be permitted under the same terms?
4. If share-alike governs the 4.3 objects, which exact licence and version must the adapted GLB files carry?
5. Is the prescribed attribution — “BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International” — sufficient if shown (a) in the application's credits, (b) in a downloadable attribution file shipped with the models, and (c) in metadata embedded in each GLB file?

We are happy to comply with whichever terms govern, including share-alike distribution of the adapted geometry if required. No version of these adapted models has been publicly released.
