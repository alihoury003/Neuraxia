# Sprint 1 spike attribution

The temporary browser model in `public/models/nervous.glb` was copied for feasibility testing from the Body Atlas project's generated nervous-system GLB. Body Atlas describes the nervous system as derived from Z-Anatomy, which is itself derived in part from BodyParts3D.

This file is **not** yet approved as Neuraxia's production anatomy source. Before any public release, Neuraxia must complete source-by-source licence clearance, preserve required attribution and share-alike terms where applicable, and exclude any assets whose provenance or licence remains unresolved.

Production-source research is documented in `../research/SPRINT_1_DATASET_AUDIT.md`.
